# OA Framework File Standards

<br>

### Name Length Limit


| File Type                        | Maximum Size   | Notes|
| :-                               | :--:           | :------| 
| Java Files                       | 50 characters  |        |
| OA Extension Component XML Files | 50 characters  |        |
| BC4J XML Files                   | 50 characters  |        |

<br>
