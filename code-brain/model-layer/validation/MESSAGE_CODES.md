## Message Token Replacements

When throwing exceptions, replace tokens dynamically:

```java
OAException error = new OAException("XXVAL", "XXVAL_REQUIRED_FIELD");
error.setApplicationModule(fieldName); // Replaces &FIELD_NAME
throw error;
```

## Usage Example

```java
// Register message in database first
INSERT INTO FND_NEW_MESSAGES VALUES (
    'XXVAL', 'XXVAL_REQUIRED_FIELD', 'US', '&FIELD_NAME is required.'
);

// Use in code
public static void validateRequired(String value, String fieldName) {
    if (value == null || value.trim().isEmpty()) {
        OAException error = new OAException("XXVAL", "XXVAL_REQUIRED_FIELD");
        error.setApplicationModule(fieldName);
        throw error;
    }
}
```
